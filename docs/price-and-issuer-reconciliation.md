# Price reconciliation and Brazilian issuer recovery

2026-10-20. Eight pinned Brazilian starter listings were matched to seven active company registrations in the official CVM CSV. `data/brazil-issuer-proof.json` retains the exact registry name, CNPJ, CVM code, status, retrieval date, previous listing provenance and SHA-256 of the downloaded source. The original CSV is public at https://dados.cvm.gov.br/dados/CIA_ABERTA/CAD/DADOS/cad_cia_aberta.csv . No personal contact fields from the full file are copied to Git.

Saved starter records with no issuer are upgraded on read only when key, original name and original provenance URL all match. Supplied mappings and edited/custom companies are never overwritten. All eight CNPJ check digits are verified in tests. This verifies corporate identity, not uninterrupted listing history or absence of corporate reorganizations. New research uses the mapped identity; prior reports stay immutable.

A second-price source is implemented using Alpha Vantage's fixed official TIME_SERIES_DAILY_ADJUSTED endpoint: https://www.alphavantage.co/documentation/#dailyadj . It requires a premium/entitled credential. GPI worker settings: `ALPHA_VANTAGE_API_KEY` and `PRICE_RECONCILIATION_ENABLED=true`. Neither was available during this release, so live reconciliation remains unperformed. No demo key or undocumented source is substituted.

The adapter is US-only until non-US vendor symbols and currency are verified. A Brazilian dataset is not advertised as independently reconciled. The adapter rejects provider quota/error messages, wrong symbol/timezone, oversized responses and malformed values. Credentials never appear in stored URLs or logs. Secondary normalized records and the raw response hash become part of the immutable dataset and downstream source hash. Raw provider response bodies are not retained by this slice.

Deterministic checks compare every primary session against the secondary series. Rebase adjusted levels to a common final date to avoid anchor differences; flag relative normalized-level errors above 0.5% and simple daily-return differences above 0.1 percentage points. These are explicit engineering tolerances, not calibrated economic truth thresholds. Missing coverage and material disagreement quarantine a dataset. No averaging, gap filling or silent repair occurs. Independent acquisition is not a certification that vendor upstream sources are independent.

By default, structurally valid single-provider histories remain usable with the visible unreconciled label to preserve existing workflows. Set `PRICE_RECONCILIATION_REQUIRED=true` on the GPI web service to require matched second-provider data for five-year portfolio calculations. Do this only after configuring an entitled feed and verifying symbol coverage. Existing immutable snapshots do not gain reconciliation retroactively; a new daily history request creates a new version. Failures preserve the last good dataset and do not mark it independently verified.

Regression checks: adjustment-anchor invariance, divergence, coverage gaps, freshness, identity, unit/timezone/source restrictions, invalid provider envelopes and CNPJ backfill boundaries. Existing price/hash/store/owner/portfolio tests continue to run. Fixtures do not prove live vendor agreement.

Browser incident: production controller logs showed known VM destruction at 08:07:06Z and replacement ready at 08:09:42Z on 2026-10-20, after the earlier HTTP 429 window. The prior polling/backoff code recovered without disabling identity or creating a blind replacement. The connected browser timed out during the signed-in visual acceptance attempt; full takeover/resume/stop usability remains unverified. No authentication bypass was used.
